



# 03 - Functions & Templates

This directory contains C++ practices and study notes focused on modular programming, function declarations, scope management, parameter passing, and template mechanics.

---

## 📜 Files & Descriptions

* `functions_1.cpp`: Demonstrates basic C++ function definition, declaration, and scope management.
* `functions_2.cpp`: Advanced function examples including parameter passing (Pass-by-Value vs Pass-by-Reference).
* `functions_3.cpp`: Password verification logic utilizing `std::string::compare()`.
* `functions_4.cpp`: An educational example featuring battery voltage monitoring logic and default parameter usages.
